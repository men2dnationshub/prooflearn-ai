# Responsible Writing Assistant

The Milestone 11 assistant makes transparent, deterministic edits for clarity,
conciseness, grammar, flow, simplification, professional tone and academic tone.
It does not accept a free-form instruction to conceal AI use or bypass detection.

The original and suggested versions remain visible side by side. Every supported
change records its goal, original phrase, replacement, explanation and number of
occurrences. The user must review facts, meaning, citations and personal voice.

An AI assistance declaration is available with every revision. The assistant is
rule based and intentionally conservative. It will sometimes return no changes,
and it does not replace expert proofreading or subject review.
